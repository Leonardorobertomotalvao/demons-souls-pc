Demon's Souls PC

Unofficial native Windows x64 port of Demon's Souls (PS3), built with static recompilation — the game's machine code is translated ahead-of-time and runs natively, without general-purpose emulation.

What is this?

A fan port for people who own the game and want to play it natively on Windows. The game's PowerPC/SPU machine code is translated ahead-of-time to C (static recompilation), compiled to a native x64 executable, and linked against hand-written clean-room reimplementations of the PS3 system libraries. Rendering goes through Direct3D 12, audio through WASAPI, and a WPF/.NET 8 launcher handles managed installation, SHA-256 integrity verification, and startup.

This project distributes no game content. No game code, data, saves, firmware, BIOS, keys or game executables are included anywhere in the repository or its releases. You must supply your own legally-obtained copy of the game; the launcher verifies file identities before letting you play.

Status

Alpha 0.2 — experimental prototype, validated on one single reference machine (the author's Windows 10 box, Ryzen 5 5500, 16 GB RAM, HDD). Verified so far: full boot up to Boletaria (logos, title screen, character creation, tutorial, the Nexus, Boletarian Palace 1-1), D3D12 rendering with shadows and particles, save/load with menu sounds, a 60 FPS runtime profile, and a root-cause fix for the startup audio-silence bug. Nothing is guaranteed on other machines; only the first area is verified, and there is no online support.

How it works

  1. Own the game. You need a legal copy of the PS3 edition (North America, BLUS30443).
  2. Decrypt locally, once. Produce an EBOOT.ELF from your own copy (e.g. RPCS3's executable dump). The project never decrypts anything for you and ships no keys.
  3. Prepare with the launcher. Download the launcher package from Releases; it imports your copy into a managed installation, verifying every component by SHA-256.
  4. Play. The launcher gates each start on approved runtime identities, then launches the native runtime at 60 FPS.

Requirements

  • Windows 10/11 x64
  • GPU with Direct3D 12 feature level 12.0+
  • The self-contained launcher package (no .NET installation needed)
  • Your own legally-obtained copy of the game, plus a decrypted EBOOT.ELF from it
  • Disk space for the managed installation (a copy of the game data)
