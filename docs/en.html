About the project

Purpose, architecture and goals — as recorded in the repository's documentation.

What it is. An experimental "Demon's Souls PC" port (Alpha 0.2) built with static recompilation, in the model of projects like Zelda 64 Recompiled: the game's executable (decrypted locally by the user) is translated once to native x64 code, producing des_boot.exe, a Windows executable. The PS3 system libraries (cellAudio, cellAtrac, camera, input, SPURS/lv2) are hand-written clean-room reimplementations.

Goals. Preserve Demon's Souls natively on PC without real-time emulation; run at 60 FPS while respecting the original 30 FPS mechanics; fix known defects with small, tested, reversible changes; and keep the project strictly legal — no game-derived material is ever published.

Honesty first. Maturity level: a working prototype, validated on one single reference machine (Windows 10, the author's computer). The verified area runs from boot to Boletarian Palace 1-1; the rest of the game is untested. Nothing here is a promise for other machines — see the limits in the downloads & requirements section.

Confirmed features

Only implemented, verified functionality from the reference machine — no promises beyond what the records prove. Evidence in the technical chronicle (docs/00–35).

Full launcher

Imports, prepares and repairs a managed installation from your local ISO or PS3_GAME folder, with SHA-256 verification of every component, identity gates (unapproved runtimes are blocked) and JSONL operation traces.

Source: launcher-alpha02-hotfix/ · chronicle: docs/32, docs/35

Native x64 runtime

The game's PowerPC/SPU machine code is converted to C ahead-of-time (AOT) and compiled into des_boot.exe — no general-purpose emulation at runtime. Complete PPU boot and recompiled SPU code images.

Source: port/ · patches/ · chronicle: docs/08, docs/09

Direct3D 12 rendering

Lit, textured scenes with shadows, HUD, particles, light shafts and haze; precompiled shaders — the game never pauses to compile shaders.

Chronicle: docs/24, docs/26, docs/28

Audio fixed at the root

The total-silence-at-boot bug (libmixer notify-queue race) was fixed and validated by A/B runs: PCM reaches WASAPI with the fix ON and does not with it OFF (3752/3752 and 8442/8442 notifications across two test sets), plus the author's listening validation.

Patch: patches/des-audio-notify-fix.patch · chronicle: docs/34

Save/load and menu sounds

Save and load working, including the game's menu sounds, with a 60 FPS profile approved via runtime identity verification.

Chronicle: docs/28, docs/33

Downloads & installation

How to get the launcher and prepare your installation — using your own legally obtained copy of the game. The project distributes no game, firmware, keys or protected data.

  1. Own the game

    The PS3 North American edition (BLUS30443). The port requires the files from your own copy; nothing is provided here.

  2. Produce the EBOOT.ELF from your copy

    Decryption happens locally, on your machine, for interoperability — recommended route: RPCS3's executable dump feature applied to your own copy. The project never decrypts anything for you and distributes no DRM circumvention tools. Details in docs/03-setup.md.

  3. Download the launcher

    Self-contained package (Windows x64, no .NET install needed). Extract the whole ZIP and run Launcher\DemonsSouls.Launcher.exe.

  4. PREPARE / REPAIR

    The launcher copies and verifies everything into a managed installation (resumable by SHA-256; your original folder is never modified) and records each operation as JSONL traces.

  5. Pick 60 FPS and PLAY

    Under Advanced, confirm an approved des_boot.exe runtime and the EBOOT.ELF from your copy. Every start verifies SHA-256 identities before releasing the button.

Download the launcher (release v0.2.1-alpha.1) All releases Instructions in the README

Documented requirements

  • Windows 10/11 x64
  • GPU with Direct3D 12 (feature level 12.0+)
  • Self-contained launcher package (no extra .NET)
  • Your own legal copy of the game (PS3 USA, BLUS30443)
  • EBOOT.ELF decrypted from your own copy
  • Disk space for the managed installation

Honest limitations

  • Experimental prototype — no stability or performance guarantees
  • Validated on one single reference machine
  • Only the first area is verified (rest of the game untested)
  • No online/network support
  • Physics above 60 FPS untested; cutscenes revert to 30 Hz
  • Audio fix validated on a single audio setup

Legal notice. An independent, unofficial fan project with no affiliation with Sony Interactive Entertainment, FromSoftware or Atlus. How to file a useful bug report

Include as much verifiable context as possible — never passwords or personal data:

  • Operating system and version (Windows 10/11)
  • Hardware: GPU, driver, RAM
  • Launcher version in use (e.g. v0.2.1-alpha.1)
  • Logs: %LOCALAPPDATA%\DemonsSoulsPCLauncher\logs\ (launcher.log and operations/*.jsonl)
  • Exact steps to reproduce, expected × actual result
  • Never attach or link game files, firmware, keys, dumps or saves
